## Actual reusable operations and constraints

`rdt_cli/client.py` supplies `search` and `get_post_comments`; `parser.py` and
`models.py` supply actual listing/post/comment parsing with `after`/`before`
cursors. The probe directly reuses these acquired implementations. It does not
call CLI authentication or credential discovery helpers, which can read host
browsers and automatically refresh cookies after their configured lifetime.

This selected route uses Reddit JSON endpoints through httpx with a supplied
session cookie, bounded delays/retries and cookie merging. Although portions of
the backend accept anonymous clients, the product probe requires an explicit
session and makes no claim that anonymous JSON access works. An OpenCLI bridge
is not the selected execution route and does not prove a Reddit session.

`rdt` source can run in a server environment with explicitly provisioned session
data; browser-cookie extraction and OpenCLI instead introduce desktop/browser
dependencies. Session expiry, account access, API changes, pagination coverage,
commercial access and rate limits still need controlled live assessment.
The copied backend also contains write operations; this probe exposes only
search and thread reading, never posting/voting/messaging.

## Probe and verification

`scripts/probes/reddit.py` loads only the pinned acquired backend, requires an
explicit bounded-size cookie file, rejects symlinks and group/world-readable
credentials, and supplies cookies directly to `Credential`. Search is capped at
five results; thread reading at five requested comments; requests use a 15-second
timeout and zero retries. It reports actual field names, counts, cursor presence,
failures and elapsed time without copying session credentials into reports.

- Offline CLI report: `status=skipped`, `validated=false`, `elapsed_ms=0`.
- Configured or bridge-only report: `status=unvalidated`, never verified.
- Added probe tests: **8 passed, 1 live test skipped**. Fixtures test actual
  acquired parsers, bounded calls, pagination, thread reading, credential boundary
  rejection and failure redaction.
- Acquired upstream parser/client/session suites: **14 passed**, with socket
  connections disabled. These verify offline source behaviour, not live access.
- Ruff check/format passed for both probe scripts/tests.
