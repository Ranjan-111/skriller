# SKR-070 — Instrument stages, source health and costs

The worker records tenant-scoped stage observations for successful and failed external calls. Each attempt has a UUID correlation identifier, one-attempt denominator, accepted-result count, bounded stage I/O and queue wait, typed outcome, and confirmed, estimated or unpriced cost. Failure text and page bodies are excluded. The usage API reports stage/source health, failure categories, correlation coverage, explicit sample counts, spend and event truncation.

Collection now emits bounded network, parser and browser durations in source summaries. The usage API aggregates these separately by collection source and attaches them to matching collecting-stage metrics. Missing component measurements remain `null` with zero samples; measured zero remains `"0"` with one sample. The client validates these bounds and the results panel labels unavailable timings and sample denominators.
