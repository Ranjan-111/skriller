# SKR-070 — Safe stage outcome and cost observations

The worker records tenant-scoped `stage_observation` events for both successful and failed external stage calls. The allowlisted event records stage, configured source, outcome, one-attempt denominator, accepted result count, external I/O elapsed seconds and confirmed or estimated cost status. Failed provider/source exception text and page content are not included; failed runs with zero results still produce an observation.

The job usage endpoint now aggregates these events by stage and source, with explicit success/failure counts, result totals, elapsed I/O, confirmed/estimated cost and unpriced observations. Aggregation validates bounded event data, limits reads to 2,000 events, ignores malformed observations while counting them, and reports truncation. The results panel displays the aggregates and malformed/truncated-data notices.
