Imported the complete `scrapling` package, tests, examples, metadata and BSD-3-Clause
license from `reference/Scrapling-main` into `third_party/scrapling` with
`python3 scripts/provenance.py import scrapling`. The manifest records 127 copied
files, including 63 files beneath `tests/`. Upstream source is unchanged. The
archive does not establish an upstream commit; the manifest leaves that field null.

dependencies from optional fetcher/browser dependencies. Importing an entry point
does not install browser executables or test navigation. Browser fetching and
live-source regressions belong to later tickets.

database was removed after the run. No code patches were necessary for the parser
