## 2026-10-18 local launch tooling

The local stack launcher now uses installed Node plus the project's installed Next
CLI instead of a global pnpm wrapper. Locked dependency installation is still required;
launch no longer depends on a global package-manager version. Dependency checks happen
before local configuration is loaded. Cleanup tolerates child exit races while stopping
all owned process groups, preserving the existing no-kill policy for other services.
Two focused launcher fixtures pass without starting services, reading local credentials,
restarting the user's app or connecting to a live account. Ruff and formatting pass.
This does not constitute a hosted deployment or customer pilot.
