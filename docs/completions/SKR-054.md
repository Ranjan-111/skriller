# SKR-054 — Private evidence-backed exports

The backend adapts the supplied ScrapeGraph-AI CSV/JSON export helpers and adds JSONL plus schema metadata. The authenticated export API operates on a tenant-owned immutable plan and trusted qualification rows. It includes confirmed records and only near matches explicitly selected by the caller; it rejects excluded and unselected records, omits unverified or unrequested values, preserves nulls and evidence references, and stores bounded private artifacts. Every download rechecks workspace authorization, artifact/evidence expiry and content integrity.

Backend checkpoint: `exports/formats.py` adapts the actual supplied ScrapeGraph-AI `utils/data_export.py` CSV DictWriter and Unicode JSON dump logic to private memory streams, union/ordered columns, empty files, explicit null metadata and CSV formula guards. JSONL extends the same serializer with a metadata record. Attribution points to the retained copied repository and MIT provenance; no source file was changed.

`exports.create_export` loads a tenant-owned immutable plan, runs trusted DB qualification, and exports only confirmed records or individually selected near matches; excluded groups and unselected near matches are rejected. Client-supplied values/Fit are never accepted. Unverified/inferred fields are omitted, contradictory accepted fields are null, and per-field evidence IDs/observation times plus source URLs, schema version and plan revision remain traceable. JSON preserves literal values/nulls; CSV preserves unknown-vs-empty through `null_fields` and marks spreadsheet formula strings with an apostrophe.

Artifacts use private EvidenceStorage blobs, scoped database IDs, content digests and bounded expiration (no later than contributing evidence expiration). The isolated authenticated POST/GET export router checks tenant membership, stored artifact kind, source evidence availability/expiry and blob integrity on every download. Responses use fixed attachment filenames, no-store/nosniff and do not expose blob keys or bearer query links. Empty JSON/JSONL include metadata; empty CSV is a valid schema header. Pilot bounds are 100 records and 2 MiB.
