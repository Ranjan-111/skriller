# SKR-064 — Bounded RSS and Atom parsing

Added a parser that consumes bytes already obtained by the guarded HTTP fetch path; it does not fetch feeds or entry URLs itself. It reuses the copied Agent-Reach feedparser dependency and the copied Agent-Reach public URL normalizer. Feed size is capped at 2 MiB, results at 100 entries, summaries at 8 KiB and identifiers at 512 characters.

Feed dates are taken from the feed's published/updated metadata and stay null when missing or invalid; fetch time is never substituted. Stable upstream IDs are retained, with a validated canonical URL fallback. Repeated IDs or links are counted and returned once. Private/non-HTTP(S) article links are dropped. Oversized summaries are explicitly labelled as truncated. Parser warnings expose only a boolean malformed flag, not source-controlled exception text.

Verification: **4 fixture tests passed** for RSS+Atom parsing, relative URLs, true feed timestamps, missing dates, duplicate links, private-link rejection, summary/input bounds, and no-network parser contract. Ruff and MyPy pass. `uv lock --check` passes.
