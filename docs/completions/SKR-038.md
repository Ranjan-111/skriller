# SKR-038 — Dynamic browser boundary

The copied Scrapling DynamicFetcher is wrapped behind a trusted isolated executor. Host browsers, CDP and existing profiles are unavailable fallbacks. Readiness, request/body limits, deadlines, shared capacity and temporary profile cleanup are bounded. Without the isolated executor, rendering returns unavailable before IO.

Initial verification: 7 controlled executor/real PostgreSQL tests passed. The later actual browser/container evidence below supersedes that initial checkpoint.

Current remaining gate: production collecting-stage HTTP-to-browser escalation integration. The standalone image, firewall and real executor are now verified as recorded below.

Status: implemented_pending_verification.
