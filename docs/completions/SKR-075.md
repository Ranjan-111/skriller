# SKR-075 local benchmark preparation

Status: **implemented_pending_verification**.

Added `scripts/probes/local_job_benchmark.py`, which measures the existing copied Scrapling/Agent-Reach page classifier and Skriller cleanup pipeline over a fixed five-file fixture corpus. It separates classifier outcomes (including empty, challenge, and JavaScript-shell fixtures) from local processing time, excludes one warmup, records p50/p95 with sample counts, hardware/Python version, fixture bytes, cache conditions, Python traced allocation peak, and platform-labelled cumulative process peak RSS. Repetitions are capped at 20. No network, browser, source account, or model calls are made.

The five-repetition diagnostic on macOS 26.5.1 arm64 / Python 3.12.11 measured 25 total fixture cases: classifier p50/p95 **0.187/0.273 ms** (25 samples), cleanup **4.653/7.435 ms** (10 readable samples), and fixture-loop case time **0.328/7.145 ms** (25 samples). It read 7,870 fixture bytes and recorded Python traced peak allocation of 8,566,578 bytes. Process peak RSS rose from 159,514,624 to 196,427,776 bytes, but is cumulative and cannot be attributed to this run. Classifier outcomes were 10 readable, 5 empty, 5 challenge, and 5 JavaScript-shell fixtures. Empty, challenge, and shell fixtures only show why static cleanup was skipped; they are not measured live source failures. These are diagnostic fixture numbers, not production latency or an SLA.

Verification: `uv run python -m pytest -q tests/probes/test_local_job_benchmark.py` — **5 passed**; Ruff check and format check passed; MyPy passed for the harness. The fixture run is recorded in [SKR-075-LOCAL.json](SKR-075-LOCAL.json).

Remaining: dependencies SKR-040, SKR-067, and SKR-074 are not fully closed. This evidence does not include real source/network/model time, a declared hosted hardware profile, end-to-end durable-job timing, isolated process memory attribution, browser-heavy concurrent work across two workspaces, or host responsiveness. Keep SKR-075 pending until those release measurements are completed.
