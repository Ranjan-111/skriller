# SKR-082/083 — Luna frontend batch

Implemented 2026-10-17. The frontend subtask is implemented and locally tested;
whole-ticket completion remains pending the backend/live gates below.

Added the owner analytics disclosure to the existing research workspace without
changing its prompt flow or visual system. Member accounts get owner-only
guidance. Owners can start explicit Google consent, select an owned connection,
refresh access, disconnect locally and request a historical daily report.

The callback route `/connections/youtube-analytics/callback` renders the existing
identity/workspace shell. Root callbacks are also supported. Only the fixed
Google consent origin/path and same-origin registered UI callback paths may be
used. Grant ID/state/expiry and initiating UID/workspace stay in tab-local session
storage. Code/state/provider query values are removed before waiting for Firebase
identity; the code remains in memory only. Completion consumes the unexpired
intent once and rejects account/workspace/state mismatch, denial and duplicates.
StrictMode completion was tested. Callback return opens the analytics panel.

The new client reuses normal bearer requests and generated API schemas. Grant
metadata rejects cross-workspace, unknown secret-bearing and mismatched-ID
responses. Reports bind to the selected grant/channel/date range and validate
numeric values, units, timezone, response hash and literal-summary contract.
Provider/configuration errors never echo response bodies or research-specific
prompt errors.

Reports retain exact day labels and numeric values, including fractional seconds,
with returned units and Pacific timezone. Missing days remain absent. Empty and
unsupported values are explicit. No revenue or model-generated summary is
invented. Reports are component memory only and clear on account/channel/date
changes or disconnect. Async generation checks prevent old requests from
populating a different account's view. No private metrics or source tokens are
stored in browser storage or workspace evidence.
