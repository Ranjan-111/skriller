## 2026-10-17 — official OAuth read executor foundation

Added a fixed `GET https://api.x.com/2/tweets/search/recent` worker launched only
through the existing isolated container runner. The request uses a workspace's
encrypted OAuth access token, rejects session-cookie credentials, redirects,
retries, arbitrary URLs and write operations, and caps responses at 1 MiB. Search
input uses the bounded `XSearch` contract. Results preserve matched X usernames,
literal post text, source URLs and provider timestamps; malformed, unattributed,
duplicate and excess results are counted or rejected without invented
engagement or qualification fields. The existing `run_connected` path fences
revoked/changed connections and checks the shared job budget.

Verification: 26 focused X parser/worker/runner tests and 14 PostgreSQL
connection/execution tests passed. Ruff, formatting and checked-module MyPy
passed. The database tests also confirm X connections reject session cookies
and accept only a stored OAuth access token. No live X request or credentials
were used.

## 2026-10-17 — durable discovery integration

The executor is now an optional discovery route when an active, unexpired
workspace OAuth connection has both `read` and `discover` scopes. Ambiguous
connections fail closed; if no eligible connection exists, the existing indexed
search route remains available. Direct X results pass through the normal
candidate deduplication, evidence persistence, checkpointing and source-capacity
lease. Rate limits stop further X calls and preserve a bounded `Retry-After` for
capacity accounting; source failures do not silently fall back and disguise the
failure. The diagnostics endpoint registers X only when its isolated image is
configured and a matching active connection exists.

Verification: **135 tests passed** across X parser/worker/runner, OAuth
connection fencing, durable research workflow, source diagnostics, billing
webhook/reconciliation suites. Ruff, formatting, checked-module MyPy and web
contract drift checks passed. No live X credentials or requests were used.
