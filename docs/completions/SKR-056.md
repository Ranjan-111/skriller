One call selects relevant complete saved source statements; output cannot paraphrase statements into accepted facts, execute code, follow links, invoke tools, fetch sources, merge chunks or retry. The original immutable plan is unchanged and the existing run's remaining model/token/deadline limits apply.

Up to five explicitly selected tenant-owned saved excerpts are checked before and after model IO. Missing, expired, deleted, changed or inaccessible evidence fails closed. Every citation must select a supplied evidence ID and its complete exact excerpt, with no duplicate, invented identifier or shortened/negation-stripped quote. Cancellation/deadline checks discard late output. Excerpt hash is computed from the quoted UTF-8 text; a separately named stored source-content hash is labelled metadata that has not been revalidated against raw bytes. Collection time and source URL/platform remain explicit.

Statements are labelled source observations that have not been independently verified. Overall coverage/relevance is not asserted from model selection. Unknowns remain explicit. Inference generation (including inferred contacts) and research expansion are labelled unavailable; no registered discovery/read operation is silently launched. Strict schema rejects extra model inference/action fields. Input and transport bounds still apply, including the copied prompt/schema overhead; oversized reports may return unknown rather than truncate or exceed the model reservation.
