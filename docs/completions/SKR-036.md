# SKR-036 — copied HTTP fetch adapter implemented and fixture verified

`src/skriller/connectors/fetch.py` uses the attributed copied Scrapling FetcherSession GET implementation and copied Response/Selector parser. It does not introduce a separate HTTP client or reimplement the fetching engine. One copied session is reused across a bounded manual redirect chain. The current guarded proxy closes individual HTTP connections, so persistent TCP reuse is not promised despite session reuse. Hidden retries, automatic redirects, browser impersonation and stealth header generation are disabled; TLS verification remains enabled. This public-read adapter rejects connected/authenticated source contexts rather than implying it can access their sessions.

An operator-configured local GuardedProxy is mandatory. libcurl environment proxy bypass is disabled, including NO_PROXY, with no direct fallback. Every redirect target passes copied public URL validation and the proxy's existing DNS/public-IP guard and numeric dialer; only standard public HTTP(S) target ports are allowed. The adapter itself is not the deployment egress firewall. Source identities must be allowed by the persisted plan.

Before each actual hop it checks workspace/job/plan/deadline/cancellation, takes a committed shared HTTP/source/host lease, and reserves exactly one fetch attempt under the locked job. Stable operation keys prevent replay; the shared reservation namespace caps one URL at3attempts and the execution context further bounds the entire redirect chain. Timeout is capped at20seconds and the remaining job/context/lease window. Source failure retains the conservative attempt estimate; completed responses confirm actual attempt accounting. Release feeds the copied Scrapling throttle/Retry-After parser. Manual redirects are counted individually and do not invent extra retry capacity.

Decoded body chunks go through a bounded libcurl callback and MAXFILESIZE_LARGE limit before the final copied parser receives the bytes. The retained buffer never extends past the configured limit (maximum5MiB); no full-body download followed by a length check is used. Slow responses and decoded oversized gzip responses return typed failures. The adapter returns separate measured engine/request and final parser durations; request timing includes the copied engine's empty response wrapper conversion, rather than claiming a pure wire-only measurement. Unsupported content, denial,429,404,empty pages and preliminary challenge markers have explicit outcomes. Complete source-aware challenge/JS-shell classification remains SKR-037.

A FetchArtifact contains source URL/final URL, timestamp, content type, decoded-byte count, SHA256, access route, page_read evidence kind, attempt count and timing. Its persist method verifies workspace, active job and unchanged bytes, then stores private raw evidence and a separate private JSON metadata evidence object referencing the raw evidence ID/object key. The real database evidence record carries its source/platform/time/hash/private key. A generic web page read is never promoted to LinkedIn profile_read or mistaken for search_snippet evidence. Blob/database crash-orphan reconciliation remains the existing storage delivery gate; this adapter does not claim distributed object/database transactions. Copied engine URL/error logs are filtered at their product boundary; typed metrics replace raw query/header diagnostics.
