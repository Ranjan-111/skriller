## Sol on-demand renewal and consent account fences — 2026-10-17

Configured Reddit discovery now automatically renews a due access token before
the initiating owner's first source read. It reuses the encrypted permanent grant
and existing one-use refresh transaction. Healthy access makes no token request;
members and other owners cannot open the initiating owner's grant. Multiple
eligible accounts are never implicitly renewed. Cancellation and a short original
job deadline prevent refresh. Replacement is compared again under the consent
lock, so a stale renewal selection cannot consume a newly rotated grant.
Retention is not extended. An uncertain refresh retires access and cannot replay;
the current discovery attempt stops native reads without indexed fallback.
Renewal runs inside the stage's wall-clock window, and cancellation waits for
the bounded token operation before releasing the stage. A metadata-only persisted
event records successful renewal. Checkpoint replay performs neither refresh nor
source I/O. No background scheduler or owner impersonation was added.

Reviewed both X and Reddit clients: authorization URLs reject userinfo/fragments,
unexpected consent fields and expired connection receipts. Account changes abort
an outstanding consent start before it can store old-account intent or navigate.
Two controlled delayed-response tests verify the actual panel side effects.

Verification: **98 distinct related backend/database/transport checks** passed
(94 grouped checks, then four additional deadline/ambiguity/kill-switch cases
within a final 11-test renewal suite). Both read and discovery kill switches
prevent token I/O. This includes actual RLS, native parser workflow,
rotated-token delivery, uncertainty/no-fallback and checkpoint replay. **207 web
tests**, Next production build, TypeScript, generated contract check, Ruff,
four-module checked-body MyPy and diff checks passed. All provider receipts were
synthetic; no source image/configuration was enabled and no real provider/model,
account or user browser request was made.

SKR-061 moves to **implemented_pending_verification** for its required live-source
