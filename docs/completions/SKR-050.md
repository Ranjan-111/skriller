# SKR-050 — qualification comparison component

Deterministic, network-free comparisons use accepted, dated, evidence-linked facts only. Unknown essential or exclusion facts, unsupported criteria, conflicting evidence, expired claims and unverified event dates cannot confirm a match. Event freshness does not use page fetch time. Preference counts rank within qualification status and are not calibrated confidence. Same-field contradictory facts stay unknown; no model invents absent facts.
