# SKR-003 — Agent-Reach source import

Imported `reference/Agent-Reach-main` into `third_party/agent-reach` with
`python3 scripts/provenance.py import agent-reach`. The copied MIT license,
package metadata (1.5.0), application source, tests, and test fixtures remain
unchanged. `third_party/agent-reach/PROVENANCE.json` records exact source hashes;
the ZIP-derived reference has no verified upstream commit SHA. No installer was
run and no external platform backend was installed.
