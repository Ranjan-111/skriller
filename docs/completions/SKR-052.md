## Earlier implementation evidence

The run view now loads the job's workspace-scoped saved plan and shows the actual interpretation status, required/preferred/excluded criteria, unsupported criteria, clarification text, and selected sources. Clarification replies now have an authenticated, idempotent endpoint. A reply appends as a separate user message, creates an immutable child plan seed and a new bounded planning job; the worker interprets the original prompt and reply together. The results view presents the saved clarification and an answer form. The original paused job and its plan remain unchanged. A PostgreSQL worker test exercises ambiguous geography through reply, planning lease and revision persistence with a controlled model.
