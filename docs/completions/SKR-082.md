# SKR-082 owner-authorised YouTube Analytics

Status: **implemented_pending_verification**. Backend OAuth/grant lifecycle and the browser connection/callback UI are implemented and locally tested; real Google consent/owner-channel and live browser acceptance remain open.

Added separate owner-only analytics grants with database RLS that excludes other owners of the same workspace. Grants use the existing private keyring/AES-GCM pattern, with workspace, initiating owner, configuration, grant ID and generation in the authenticated encryption context. A 10-minute consent starts only with explicit opt-in and requests the two read-only YouTube scopes. The authorization URL uses PKCE S256. Authenticated completion matches the owner, state hash, expiry and fixed client/redirect configuration; it commits single-use consumption before exchanging the code. Returned scopes must match, and `channels.list(mine=true)` must identify exactly one owner channel. No generic/public YouTube connection is upgraded into owner analytics.

Refresh uses a committed single-flight generation, preserves the absolute 30-day grant expiry, and rejects a late result after revoke or ownership loss. Local revocation wipes encrypted credentials; remote Google revocation is explicitly reported as not performed. A failed or interrupted exchange/refresh requires renewed consent instead of blind replay. Expired grant ciphertext is removed by owner listing and the existing retention worker; a narrowly scoped privileged expiry function covers co-owner grants without exposing their tokens. Actual offline restore clears all restored analytics grants, including co-owner grants. No OAuth client or source credentials were added to local configuration.

The OAuth/metrics/summary/actual restore suite passed **49 tests**. Related public YouTube, retention, existing connections and schema checks passed **18 tests**, with one existing opt-in live source test skipped. Ruff, MyPy for 11 source modules, generated OpenAPI/client drift and TypeScript checks passed. All Google traffic was represented by offline HTTP transports or controlled providers; no Google or model provider was called.
