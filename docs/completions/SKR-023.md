# SKR-023 — shared capacity verified

Migration0010 adds owner-managed PostgreSQL resource leases and persisted source/host cadence. Restricted tenant sessions can call only membership-checked functions; direct global state access is denied. The owner functions use one transaction advisory lock to serialize admission across application processes and bypass only these private capacity tables' RLS, with a fixed search path and no public execute privilege. They verify the scoped active job before admission. Caps are deployment-managed pilot constants:8 HTTP tasks,2 browser pages,1 model task,1 task per source and target host, and2 distinct externally active jobs per workspace. Callers cannot raise them. This single pilot database applies the HTTP/browser cap across the deployment, conservatively stricter than per worker host.

Leases expire in1–120seconds. Expired or foreign tokens cannot release a successor or change cadence. StageHandler has optional trusted resource/source/host identity; external handlers using it must implement the deadline-aware callback. CheckpointWorker commits admission before I/O, declines an occupied resource before budget reservation or external-call audit creation, and releases it in finally after I/O. The callback receives the remaining job/attempt/capacity window, including transaction time. Unsupported fixture-only handlers retain their existing explicit local behavior; production handlers must configure capacity rather than omit it. Network cancellation and subprocess termination remain connector/runner responsibilities, because an SQL lease cannot terminate external I/O.

Throttling is imported directly from the attributed copied Scrapling AutoThrottle and parse_retry_after implementations; neither algorithm was recreated. Feedback is persisted for both source and host. Retry-After seconds and HTTP dates remain floors; nonfinite waits fail conservatively at the bounded86400second maximum. Typed provider Failure retry_after_seconds is passed through by the worker without persisting raw headers or errors. Source minimum cadence can be stricter than adaptive timing. Failed stages retain existing conservative charge accounting and do not automatically retry.
