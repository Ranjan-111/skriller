# SKR-065 — Public YouTube metadata and caption evidence

Implemented the isolated YouTube read and local job pipeline. The worker reuses Agent-Reach's installed yt-dlp backend, pinned to 2026.8.19 in uv.lock, and its provided runtime check. It preserves single-video identity, source publication date, fractional duration, public metadata counters and available English WebVTT captions. Provided captions and platform automatic captions have separate origin labels. Missing/failed/unsupported captions remain explicit; no audio download, transcription service or generated substitute is used.

The new image installs six hash-checked wheels offline over the existing immutable browser base. It reuses that base's pinned Playwright Node runtime (v24.21.0) for yt-dlp's bundled JavaScript support; remote components remain disabled. Execution uses the existing guarded runner: unprivileged UID, no capabilities after setup, read-only root, bounded temporary workspace, proxy-only firewall, hard timeout and confirmed container cleanup. No host sessions or source credentials are mounted. Agent-Reach's copied doctor returns `warn` because it expects a user config file; the worker supplies its Node options explicitly. This warning is retained, rather than promoted to verified live source readiness.

The pinned yt-dlp urllib handler is reused with bounded request and redirect accounting; alternative transport fallback is disabled. Twelve HTTP attempts are reserved before execution and reconciled with the worker's observed count. Unknown failures use the existing estimated reservation accounting. Shared source capacity, source switches, cancellation, tenant checkpoint replay and privacy suppression apply. The optional `SKRILLER_PUBLIC_YOUTUBE_IMAGE` must be an immutable image ID and requires the guarded collection proxy; it remains unset locally.

Successful reads store scoped video evidence and up to 20 caption citations with exact cue times and timestamped video links. Longer/omitted cues are counted. Public counters use video-specific fields; captions do not establish creator identity. Videos remain distinct from person/company leads during qualification. Expired evidence removes metadata and caption previews from the public result view and makes citations unavailable. The API and generated client schema expose the optional typed `youtube` view.

The web client now validates the optional YouTube view at runtime, including source host, public counter bounds, unknown identity, caption state/origin/language and the 20-segment cap. Older result payloads without this field remain valid. The workbench offers YouTube as an optional source. Results label public counters separately from private Analytics, distinguish provided and platform-automatic captions and all unavailable/read-failure states, show cue times with YouTube timestamp links, load each scoped citation on request, and hide expired metadata or text. No caption is described as generated by Skriller.

The installed-image fixture also passed using actual yt-dlp extraction processing, supplied captions and `--network none`, with non-root execution, zero capabilities and cleanup confirmed.
