# SKR-065 — Public YouTube metadata and caption evidence

Added a bounded parser for the existing reviewed, isolated `youtube_metadata` runner output. It preserves the video's source ID, title/channel, publication date, description, duration and public view/like counters; counters are explicitly labelled `public_metadata` and `observed_at` remains distinct from the source publication date. It records caption-language availability without claiming transcript text was retrieved or generated. A WebVTT parser preserves cue start/end times, exact text, public video URL and observation time as `youtube_caption` evidence, and rejects unsupported format, oversized input, private URLs and invalid timestamps.

No network access, login, cookie, challenge solving, audio download or transcription provider is introduced. Agent-Reach's copied YouTube channel was inspected; its provided `transcribe` function downloads audio and calls a paid Whisper API, so it is not used for caption extraction. The product continues to use the already reviewed isolated metadata command.

Verification: **5 fixture tests passed** for public metadata/date/counter labels, missing captions remaining unavailable, caption-language state without invented text, timestamp/source preservation, video identity and URL checks, and byte bounds. Ruff and MyPy pass.

Ticket remains `implemented_pending_verification`: WebVTT retrieval from available captions is not yet wired through the isolated worker output, and the current browser worker image's yt-dlp installation/runtime needs verification. Tenant evidence persistence, shared stage-budget accounting, and result/qualification integration are also open. No live video or transcript request was made.
